# خُطوة — مختبر أساسيات البرمجة

مشروع تعليمي تفاعلي يشرح مفاهيم برمجية مشتركة بين لغات كثيرة، مع أمثلة قابلة للتبديل بين Python وJavaScript وJava وC++.

## تشغيل المشروع

1. فك ضغط مجلد المشروع إذا استلمته كملف ZIP.
2. افتح المجلد في Visual Studio Code.
3. افتح `index.html` في المتصفح. لا توجد مكتبات أو خطوات بناء مطلوبة.

يمكن أيضاً فتح المجلد عبر إضافة Live Server في VS Code لتحديث الصفحة تلقائياً بعد حفظ التغييرات.

## محتويات المشروع

- `index.html` — بنية الواجهة.
- `styles.css` — التصميم والحركات.
- `app.js` — الدروس، خطوات التنفيذ، الرسوم، وبرومبت Google Flow.

## الدروس

1. الإدخال والإخراج.
2. المتغيرات وأنواع البيانات.
3. العمليات والتعابير.
4. القرارات `if / else`.
5. التكرار `for`.
6. التكرار `while`.
7. الدوال والنتائج.
8. القوائم والمصفوفات والفهرسة.

يمكن تعديل أرقام العمليات، وعدد تكرارات الحلقات، ومدخل الدالة، وعناصر القائمة؛ ويتحدث الكود والمشهد وبرومبت Google Flow وفق القيم الجديدة. زر التشغيل يفعّل حركة عناصر المشهد ومؤشر السطر، والإيقاف المؤقت يثبت الحركة. زر الخطوة التالية يعرض كل مرحلة على حدة، ويمكن تغيير سرعة التشغيل من القائمة. الواجهة بتصميم ورقي هادئ (حبر وطين وزيتوني)، وتتكيّف أعمدتها وأزرارها مع شاشة اللابتوب والموبايل.

المشاهد التعليمية أمثلة موجهة وليست منفذاً عاماً لأي كود يكتبه المستخدم. زر Google Flow يجهز برومبت نصياً من الدرس والقيم المختارة؛ نقل البرومبت إلى Flow يتم يدوياً.
